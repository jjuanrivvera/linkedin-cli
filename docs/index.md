# linkedin

A read-only, agent-friendly CLI for **LinkedIn job search** via the unofficial **Voyager** API.

!!! warning "Unofficial API — use at your own risk"
    This drives LinkedIn's private endpoints with **your own browser session cookies**. It is not
    sanctioned by LinkedIn and may violate the User Agreement; automated access can get your account
    restricted. Ban-safety (paced delays, a daily cap, no retry on throttles) is **on by default**.
    Use your own account, low volume, your own machine.

See the [command reference](commands/linkedin.md) and [getting started](getting-started.md).
